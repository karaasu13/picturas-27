# Medições da Fase 2

Scripts, dados e resultados das medições dos dois requisitos não funcionais da Fase 2
(modularidade do processamento de vídeo e capacidade/comportamento temporal), antes e depois do
refactoring.

| Caminho | Conteúdo |
|---|---|
| `ambiente.md` | Máquina, versões, código medido e condições para repetir as medições |
| `scripts/` | Scripts de medição e de regressão (como correr em `scripts/README.md`) |
| `baseline/` | Resultados em bruto no commit base `0523102` |
| `final/` | Resultados em bruto depois do refactoring (e as medições excluídas, cada uma com o seu `LEIA-ME.md`) |
| `comparacao-baseline-final.md` / `.csv` | Comparação entre a baseline e a solução final, com alvos e mínimos |
